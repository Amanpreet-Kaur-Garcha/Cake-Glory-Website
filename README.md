# Cake Glory Website
Cake Glory is a static bakery-themed website developed using HTML and CSS as a frontend practice project. The project focuses on webpage structuring, layout organization, and basic UI design.

The website showcases a fictional cake shop with visually organized sections and simple styling.

## Features
- Bakery-themed homepage
- Product showcase sections
- Navigation bar implementation
- JavaScript image slideshow
- Footer and contact section
- Basic webpage layout design

## Tech Stack
- HTML5
- CSS3
- Notepad

## Learning Outcomes
- HTML page structuring
- CSS styling techniques
- Layout organization
- Basic UI design principles
- Frontend development fundamentals

## Future Improvements
- Add responsive design using media queries
- Improve slideshow controls and animations
- Add interactive product sections
- Improve UI consistency and styling
- Add backend support for orders/contact forms
